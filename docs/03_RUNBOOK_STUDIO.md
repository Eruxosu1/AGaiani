# Инструкция: работа со Studio и съёмка клипов

Пути ниже относятся к `E:\uTorria\Downloads\MOHS2` (в документах называется MOHS2).

## 1. Запуск Studio
Запускайте `StudioNEOV2` через Mod Organizer (выбрать в списке запуска -> Run). Загрузите персонажа (кнопка `add` слева -> персонаж, карточка Main). Выбор персонажа в списке Workspace справа открывает его панели.

## 2. Ручная установка мода (если установщик Mod Organizer не принял архив)
1. Создайте папку `MOHS2\Mods\[plugs]ИмяМода\`.
2. Распакуйте архив в неё так, чтобы получилось `Mods\[plugs]ИмяМода\BepInEx\...` (как у остальных плагинов).
3. В Mod Organizer нажмите F5, включите галочку у нового мода.
4. Запустите Studio через Mod Organizer.
Так был установлен VideoExport v1.8.

## 3. Прозрачный скриншот
1. Уберите карту (кнопка `MAP` слева внизу): за персонажем не должно быть 3D-объектов.
2. Нажмите Shift+F11: откроется «Screenshot settings». Размер 1080x1920 (вертикальный формат для шортов), «Transparent background» = **Composite**, upsampling 2x или больше.
3. Нажмите F11 (Capture Render). Кнопка «Open screenshot dir» в этом окне открывает папку со снимками.
4. Проверка: `python tools/clip/check_alpha.py "<путь к PNG>" --out renders/alpha_check`. Посмотрите `renders/alpha_check_green.png` и `renders/alpha_check_hair_crop.png`: края волос должны быть мягкими.

## 4. Анимация персонажа
Выберите Main в Workspace, нажмите `anim` (левая панель) и выберите позу или анимацию. Для циклов нужны анимации, а не статичные позы. Сцену сохраняйте через кнопку `system`, чтобы не собирать заново.

## 5. Запись клипа через VideoExport
1. Ctrl+E открывает окно «Video Export 1.8».
2. Capture Settings: **Screenshot Tool = Screenshot Manager** (он умеет прозрачность), Capture Type = Normal.
3. Framerate: **30** для шортов (60 нужен только для плавных движений). Video Framerate ставьте таким же.
4. Dynamic Bones Update Mode: попробуйте «Every Frame» (для стабильной физики волос при постоянном шаге кадров; не проверено).
5. Limit By: Seconds (Limit Count = длина клипа) или Animation (длина анимации, получаются идеальные петли).
6. Other Settings: **выключите «Auto Delete Images»**, иначе кадры удаляются после сборки видео.
7. Start Recording (или Ctrl+Shift+E). Игра будет работать медленно: это нормально (около 0.4 с на кадр при 1080x1920).
8. Результат: mp4 появляется в `MOHS2\Output\`; кадры (если галка выключена) ищите рядом с ним и в подпапках, а если не нашли, отсортируйте по дате изменения файлы `*.png` во всей папке MOHS2.
9. Режим «Screenshot tool» можно сменить на Built-in (пишет BMP без прозрачности) или Win32: для альфы они не подходят.

## 6. Видео с прозрачным фоном из кадров
```
python tools/clip/frames_to_alpha.py <папка_с_кадрами> --fps 30 --out renders/clip1 --formats webm,mov --feather 0.8 --preview
```
- `renders/clip1.webm`: VP9 с прозрачностью (лёгкий, для сайта и браузера).
- `renders/clip1.mov`: ProRes 4444 с прозрачностью (очень тяжёлый, для монтажа в видеоредакторе).
- `renders/clip1_preview.mp4`: персонаж на зелёном фоне, чтобы оценить края.
- Звук: `--audio voice.wav`. ffmpeg должен быть в PATH или в переменной `FFMPEG`.

## 7. Профиль AniSFW в Mod Organizer
Для лёгкого и безопасного рендера сделайте отдельный профиль: Mod Organizer -> Profiles -> Create (скопировать из `Game`) -> отключить все моды, кроме нужных (Studio, Timeline, HS2PE, FKIK/AdvIK, Screenshot Manager, VideoExport, мокап-анимации, необходимые базовые). Это уменьшит нагрузку и исключит откровенный контент из сцены.

## 8. Частые проблемы
- «Ни один из плагинов установки не смог обработать архив»: ставить вручную (раздел 2).
- Кадры не найдены: проверьте галку «Auto Delete Images» и папку `Output`.
- В PNG нет прозрачности: нет режима Composite или за персонажем есть 3D-объект (карта, пол).
- Игра виснет при записи: уменьшите размер кадра или upsampling.
