# Лицензии, безопасность контента, правила платформ

Это чек-лист, а не юридическое заключение. При сомнениях спрашивайте юриста.

## Лицензии и права
- [ ] **Ассеты игры** (сетка, текстуры, одежда, волосы базовых наборов) принадлежат Illusion. Пробный Main собран только из них. Условия использования для коммерческой рекламы прочитать и записать вывод в `docs/02_STATE.md`.
- [ ] Если в персонаже появятся **моды**: для каждого мода найти автора и условия (`audit_card.py` выдаёт список и авторов), хранить решение «разрешено / нужно запросить / заменить».
- [ ] В ТЗ записано требование: модель только с лицензией на коммерческое использование, не чужой персонаж, голос не клон реального человека.
- [ ] **Музыка и голос**: только с лицензией на коммерческое использование.
- [ ] В репозиторий не попадают: игра, моды, архивы, видео, модели (см. `.gitignore` и список блокировок в `scripts\sync-to-github.ps1`).

## Контент в кадре
- Только SFW: в кадре, превью, описаниях и названиях файлов нет откровенного содержимого.
- Персонаж оригинальный и **явно взрослый** (черты лица, пропорции, одежда). Это упрощает отношения с площадками и зрителями.
- Для рендера используется отдельный профиль Mod Organizer `AniSFW`, где нет откровенных модов.
- Одежда обычная, без вызывающих вариантов; кадры не акцентируют тело.

## Правила платформ (проверить до публикации)
- YouTube: флаг «изменённый или синтетический контент», пометка в описании, что ведущая ИИ-персонаж. Актуальные правила проверить перед запуском.
- TikTok: метка AI-генерируемого контента. Актуальные правила проверить.
- Массовые однотипные автошорты могут попасть под политику о неоригинальном или шаблонном контенте: нужны разные сюжеты, тексты и «миры».
- Кейсы и лутбоксы в шортах не показывать; проверить правила платформ о рекламе азартных механик.
- Ролики с упоминанием сайта: проверить требования к маркировке рекламы в вашей стране.

## Секреты
- Токены и ключи не хранить в файлах репозитория (`.env` в `.gitignore`).
- Токены GitHub, которые вы показывали в чате с нейросетью, лучше удалить в настройках GitHub после работы (Settings -> Developer settings -> Personal access tokens).
