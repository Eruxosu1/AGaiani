# Обзор проекта AGaiani

## Что это
Ани: ИИ-ютуберша и «жительница» сайта ANIMAGROSS. Исходное ТЗ (30.10.2026) лежит в `docs/TZ_ANI_v1_2026-10-30.pdf`. Оно описывает сайтовую часть (аккаунт, экономика, каталог действий, служба `ag-vtuber`, сцена `/vtuber/stage`). Этот репозиторий отвечает за другое: **как Ани выглядит и как из неё делать видео** (визуал и конвейер рендера), а также за стыковку с tgKAI (раздача в YouTube, TikTok и др.).

## Цель
Единая реклама проекта на базе Ани: шорты и ролики для YouTube Shorts, TikTok, VK Клипов, позже живые эфиры. Ани представляет новые фигурки сайта, ролики промо-конвейера, конкурсы.

## Ключевые решения (на 2026-11-25)
1. **Персонаж делается в Honey Select 2 Studio** (сборка MOHS2 на Mod Organizer). Studio используется как рендерер: все шейдеры, волосы и мимика остаются родными, ничего не «плывёт», как у видеонейросетей.
2. **Экспорт в VRM/glTF отложен** как запасной путь (шейдеры не переносятся, физику волос и одежды пришлось бы пересобирать, тяжёлые текстуры).
3. **Сначала без кода:** библиотека зацикленных клипов (покой, говорит, радуется, удивляется, думает, машет) с прозрачным фоном. Потом свой плагин `AniBridge` для настоящей синхронизации губ и живого управления.
4. Персонаж **оригинальный, взрослый, SFW**. Пробная карточка `Main` собрана только из ассетов игры (проверено, см. `docs/02_STATE.md`).
5. Раздача идёт через tgKAI (animagross), подробности в `docs/06_TGKAI_INTEGRATION.md`.

## Принципы
- На экране всегда SFW. Откровенного контента в кадре, превью и описаниях нет.
- Ани всегда помечена как ИИ-персонаж (YouTube: флаг синтетического контента, TikTok: метка AI-контента).
- Из игры и модов в git ничего не попадает (ассеты принадлежат их авторам).
- Всё выключаемо и проверяемо: каждый шаг конвейера пишет результат в журнал.
- Тяжёлые GPU-задачи по одной (RTX 2060 Super, 8 ГБ).
