# Архитектура конвейера

Статус: черновик целевой схемы. Этапы A-B работают без кода по ручной цепочке, этап D автоматизирует её.

## Поток
```
событие (новая фигурка, конкурс, расписание)
   |
   v
сценарий ролика (текст, эмоция, жест)  <-- человек или локальная LLM
   |
   v
TTS: аудиофайл реплики (wav)
   |
   v
Studio + AniBridge (этап D)  ИЛИ  готовая библиотека клипов (этап A)
   |   выражение лица, рот под аудио, поза, камера; покадровая съёмка
   v
PNG-кадры с альфой (renders/<clip_id>/frames/)
   |   tools/clip/frames_to_alpha.py
   v
WebM/MOV с прозрачностью + аудио
   |   наложение на промо-кадры (ffmpeg / compose.ts из animagross), субтитры, музыка
   v
готовый шорт 1080x1920  -> очередь одобрения -> tgKAI -> YouTube / TikTok / VK
```

## Компоненты
| Часть | Где | Статус |
|---|---|---|
| Сборка с Studio | `MOHS2` (вне git) | есть |
| Персонаж Main | `character/`, карточка в `MO\overwrite` | пробный |
| Съёмка кадров | Screenshot Manager + VideoExport | работает вручную |
| Кадры -> видео с альфой | `tools/clip/frames_to_alpha.py` | готово, проверено |
| Проверка прозрачности | `tools/clip/check_alpha.py` | готово |
| Управление персонажем | `aibridge/` (C#, BepInEx) | заготовка, этап D |
| Раздача в соцсети | tgKAI (animagross) | этап C |

## Черновик протокола AniBridge (этап D)
Плагин слушает локальный WebSocket (только 127.0.0.1), принимает JSON-команды:
```json
{"id": "c1", "type": "load_scene", "scene": "ani_idle.png"}
{"id": "c2", "type": "say", "audio": "renders/c2/voice.wav", "emotion": "happy", "gesture": "wave"}
{"id": "c3", "type": "render", "fps": 30, "size": [1080, 1920], "out_dir": "renders/c2/frames", "until": "audio_end"}
{"id": "c4", "type": "stop"}
```
Ответ: `{"id": "c2", "ok": true}` или `{"id": "c2", "ok": false, "error": "..."}`.
Рот двигается по громкости аудио (первый шаг), позже по виземам. Эмоция задаёт набор параметров лица (таблица «эмоция -> параметры» хранится в репозитории, не в модели).

## Манифест клипа (черновик)
```json
{"id": "c2", "fps": 30, "size": [1080, 1920], "frames_dir": "renders/c2/frames",
 "audio": "renders/c2/voice.wav", "duration_s": 6.2, "emotion": "happy", "text": "Привет!"}
```

## Производительность (замер 2026-11-25)
- Съёмка: около 0.4 с на кадр при 1080x1920 (300 кадров за ~2 мин). Клип 15 с при 30 к/с = 450 кадров, около 3 минут.
- Видеокарта одна (2060 Super, 8 ГБ): промо-режиссёр на локальной Ollama, апскейл Real-ESRGAN и Studio **не запускать одновременно**. Рендер Ани держать в «ночном окне» или выносить LLM на внешний API.
