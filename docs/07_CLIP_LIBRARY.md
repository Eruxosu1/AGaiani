# Библиотека клипов Ани

Цель: набор коротких прозрачных клипов, из которых монтируются шорты и ролики. Любой клип можно перерисовать, когда появится финальная Ани: достаточно подставить новую карточку персонажа и снять те же сцены заново.

## Главный принцип: «домашняя поза»
Все клипы начинаются **и заканчиваются** в одной и той же позе (`idle`). Тогда их можно склеивать в любом порядке: `idle -> wave -> idle -> talk_a -> idle -> happy -> idle`. Камера, свет и положение персонажа в кадре одинаковые во всех сценах (сцену `idle` сохраните и копируйте).

## Съёмка
- Размер 1080x1920, **30 к/с**, прозрачный фон (Composite, пустая карта), камера по пояс, фиксированная.
- Профиль Mod Organizer `AniSFW` (без откровенных модов).
- Позы и анимации только нейтральные: стоя, жесты руками, повороты головы. Откровенные анимации не использовать.
- Запись через VideoExport (раздел 5 в `docs/03_RUNBOOK_STUDIO.md`). Для зацикленных клипов удобно «Limit By = Animation».

## Список клипов (первая версия)
| Клип | Длина | Цикл | Эмоция | Что в кадре |
|---|---|---|---|---|
| `idle` | 4 с | да | neutral | дыхание, моргание, лёгкое покачивание |
| `talk_a` | 3 с | да | neutral | говорит: рот открывается и закрывается, небольшие жесты |
| `talk_b` | 3 с | да | neutral | то же, другая жестикуляция (чтобы не повторялось) |
| `happy` | 2 с | нет | happy | улыбка, радость, возврат в idle |
| `surprised` | 2 с | нет | surprised | удивление, возврат в idle |
| `think` | 3 с | да | neutral | задумалась, взгляд вверх/в сторону |
| `wave` | 2.5 с | нет | happy | приветствие рукой, возврат в idle |
| `point` | 2 с | нет | neutral | указывает в сторону (место для текста или фигурки при монтаже) |

Рот у `talk_*` двигается общей петлёй, без точной привязки к голосу. Точная синхронизация губ появится в плагине AniBridge (этап D).

## Сборка клипа
```
python tools/clip/build_clip.py "<папка_кадров>" --name idle --fps 30 --loop --emotion neutral
python tools/clip/build_clip.py "<папка_кадров>" --name wave --fps 30 --emotion happy
```
Результат: `renders/library/ani_main/<клип>/clip.webm` + `clip.json`, общий список `renders/library/index.json`. Библиотека лежит в `renders/` и в git не попадает (большие файлы), поэтому делайте её резервную копию вручную.

- Для циклов скрипт считает **шов**: отношение разницы «последний кадр -> первый» к обычной разнице соседних кадров. Около 1: петля незаметна. Заметно меньше 0.3: последний кадр дублирует первый, уберите его (`--trim 0 N-2`). Больше 1.5: поза в конце не совпадает с началом, обрежьте по точке, где поза повторяется.
- `--trim ОТ ДО` берёт только часть кадров.

## Проверка прозрачности
Проводник Windows показывает прозрачный WebM с чёрным фоном: это нормально. Откройте `tools/clip/alpha_viewer.html` в Chrome или Edge, выберите `.webm` и меняйте цвет фона.
