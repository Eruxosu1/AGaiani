# Карточки персонажей

Сюда кладите карточки персонажей Ани (PNG из Honey Select 2): только SFW-варианты, только взрослые персонажи, только ассеты игры или свои.

Рабочая карточка пробного персонажа: `MO\overwrite\UserData\chara\female\HS2ChaF_20261125100901243_Main.png` (внутри MOHS2, в git не входит).
Скопируйте сюда копию как `character/Main/HS2ChaF_20261125100901243_Main.png`, если хотите хранить её в репозитории (файл небольшой, ~115 КБ).

Перед тем как карточка станет «официальной Ани», прогоните `tools/mohs2/audit_card.py` и запишите результат в `docs/02_STATE.md`.
