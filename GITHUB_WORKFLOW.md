# GitHub-workflow проекта AGaiani

Этот файл: инструкция для вас и «паспорт проекта» для нейросети. Прикрепляйте его к новому чату вместе с `docs/02_STATE.md` и `docs/01_PLAN.md`: нейросеть не помнит прошлые чаты.

> ⚠️ **В этот файл нельзя вставлять токены, пароли и ключи.** Токен отправляется только в сообщении чата.

## 0. Схема

```
D:\AGaiani (источник истины) ──автосинхронизация, каждые 10 мин──► GitHub (приватный репозиторий)
        ▲                                                              │ токен «только чтение»
        │ вы накатываете .patch (scripts\apply-patch.ps1)              ▼
        └───────────────────────────────────────────────  нейросеть: читает код и документы, готовит .patch
```

## 3. Первый запуск (один раз)

1. На GitHub создайте **пустой приватный** репозиторий `AGaiani` (без README и .gitignore).
2. Создайте папку проекта и инициализируйте git:
   ```powershell
   mkdir D:\AGaiani
   cd D:\AGaiani
   git init -b main
   ```
3. Положите файл `agaiani-init.patch` в `D:\AGaiani` и примените его (сам скрипт `apply-patch.ps1` придёт внутри этого патча, поэтому первый раз вручную):
   ```powershell
   git apply --ignore-whitespace --check agaiani-init.patch
   git apply --ignore-whitespace agaiani-init.patch
   Remove-Item agaiani-init.patch
   ```
4. Подключите GitHub и сделайте первый коммит:
   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File scripts\init-repo.ps1 -RemoteUrl https://github.com/Eruxosu1/AGaiani.git
   ```
   Если GitHub попросит вход, войдите через окно браузера (Git Credential Manager) или используйте свой токен с правом записи.
5. Включите автосинхронизацию:
   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File scripts\install-sync-task.ps1
   ```
6. Скопируйте в `D:\AGaiani\character\Main\` карточку Main (по желанию) и файл `MOHS2_scan\summary.md` положите куда-нибудь рядом: в git он не обязателен, но удобен для чата.

## 4. Обычный цикл

1. Работаете в `D:\AGaiani`. Автосинхронизация сама отправит изменения на GitHub.
2. Нужна помощь: создаёте токен только на чтение (раздел 6), прикрепляете этот файл, `docs/02_STATE.md`, `docs/01_PLAN.md` и пишете задачу по шаблону.
3. Получаете `.patch`, кладёте в `D:\AGaiani`, накатываете:
   ```powershell
   cd D:\AGaiani
   powershell -NoProfile -ExecutionPolicy Bypass -File scripts\apply-patch.ps1 -Patch имя.patch -Message "Краткое описание"
   ```
   Скрипт сам: ставит синхронизацию на паузу, проверяет патч (`git apply --ignore-whitespace --check`), применяет, удаляет патч, коммитит (`--no-verify`), пушит и **всегда** включает синхронизацию обратно.
4. Запускаете нужную команду, смотрите результат, обновляете `docs/02_STATE.md` и чекбоксы в `docs/01_PLAN.md`.
5. Удаляете токен.

## 5. Автосинхронизация

`scripts\sync-to-github.ps1` каждые 10 минут коммитит и пушит изменения. Блокирует коммит, если в изменениях есть секреты, файлы игры и модов, веса, видео или файлы больше 90 МБ. Лог: `Get-Content "$env:LOCALAPPDATA\agaiani-sync\sync.log" -Tail 30`.

Управление: `Start-ScheduledTask / Disable-ScheduledTask / Enable-ScheduledTask -TaskName "AGaianiGitHubSync"`.

## 6. Токен для нейросети (только чтение)

github.com/settings/personal-access-tokens/new → имя `claude-read`, срок 7 дней, репозиторий только этот, права: **Contents → Read-only**. После работы удалите токен.

Шаблон сообщения:
```
Прикрепил GITHUB_WORKFLOW.md, docs/02_STATE.md, docs/01_PLAN.md.
Репозиторий: <ссылка>
Токен (только чтение): <ТОКЕН>
Ветка: main
Задача: <что нужно>
Где в проекте: <файл, этап из плана>
Как должно работать после правки: <результат>
Результат: .patch файл + коротко что изменено и как проверить.
```

## 7. Если патч не применился

Пришлите нейросети текст ошибки целиком. Откат: `git checkout .` (не закоммиченное) или `git revert HEAD --no-edit` и `git push`.

## 8. Правила безопасности

Репозиторий всегда Private. В git нет секретов, игры, модов, видео и весов моделей. Нашли секрет в истории: считайте его скомпрометированным и перевыпустите.

## 9. Инструкция для нейросети

1. Токен только на чтение. Не выводи его в ответах и файлах.
2. Клон: `git clone --depth 1 https://x-access-token:<ТОКЕН>@github.com/<владелец>/<репо>.git`. Если сеть закрыта, скажи сразу.
3. Сначала прочитай `docs/02_STATE.md`, `docs/01_PLAN.md`, `docs/00_OVERVIEW.md`, потом код. Не гадай по названиям; непроверенное помечай как непроверенное.
4. Результат: `.patch` с путями от корня репозитория (применяется `git apply` в `D:\AGaiani`) и краткое описание: что изменено, как проверить, риски. Каждый патч обновляет `CHANGELOG.md`, а если менялось состояние проекта, то и `docs/02_STATE.md` и `docs/01_PLAN.md`.
5. Пользователь на Windows/PowerShell. Файлы `.ps1` держи в ASCII (без кириллицы), иначе PowerShell 5.1 ломает кодировку.
6. Проверяй на клоне (тесты, запуск) и честно сообщай результат. Код плагина на C# нельзя проверить без SDK: так и скажи.
7. Контент: только SFW; все персонажи взрослые; откровенных сцен, названий и описаний нет.
8. Ассеты игры и модов в репозиторий не добавляй.
9. Минимальные правки под задачу; неоднозначность сначала уточняй.
